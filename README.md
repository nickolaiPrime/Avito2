# Avito2 - Лента объявлений

## Описание проекта

Avito2 - Android-приложение с лентой объявлений. Проект выполнен по заданию P3 «Лента объявлений», взятому из маршрутов по ролям в Moodle.

Приложение загружает объявления из локального JSON-файла, отображает их в виде карточек и поддерживает поиск, фильтрацию по категориям и постраничную загрузку.

## Используемые технологии

- Kotlin
- Jetpack Compose
- Material 3
- Paging 3
- Kotlin Coroutines и Flow
- Koin (Dependency Injection)
- Coil 3 (загрузка изображений)

## Реализованные возможности

- Локальный источник данных с 1200 объявлениями.
- Загрузка данных из JSON-файла.
- Кэширование разобранного списка объявлений в памяти.
- Пагинация с помощью Paging 3.
- Отображение объявлений в виде сетки из двух колонок.
- Загрузка изображений через Coil 3.
- Поиск по названию, описанию и местоположению.
- Фильтрация объявлений по категориям.
- Обработка состояний загрузки и ошибок.
- Возможность повторной загрузки при возникновении ошибки.

## Пагинация

Для загрузки объявлений используется Paging 3.

Основные параметры:
- pageSize = 20
- initialLoadSize = 60
- prefetchDistance = 5

Реализованы расчёт ключей предыдущей и следующей страниц, а также getRefreshKey().

## Структура проекта

- `data` - работа с источником данных, DTO, mapper и PagingSource.
- `domain` - модели и интерфейсы Repository.
- `presentation` - интерфейс приложения, экраны, компоненты и ViewModel.
- `app/src/main/assets/ads.json` - локальный JSON-файл с объявлениями.

## Запуск проекта

1. Скачать или клонировать репозиторий:

```bash
git clone https://github.com/nickolaiPrime/Avito2.git
```

2. Открыть проект в Android Studio.
3. Дождаться завершения Gradle Sync.
4. Выбрать конфигурацию `app`.
5. Запустить приложение на эмуляторе или Android-устройстве.

Для сборки через терминал:

```bash
./gradlew assembleDebug
```

В Windows:

```bash
gradlew.bat assembleDebug
```

## Что не реализовано

- Debounce для поискового запроса.
- Pull-to-refresh.
- Экран подробной информации об объявлении.
- Рабочее избранное с локальным сохранением.
- Профилирование производительности прокрутки.
- Автоматические тесты Repository, ViewModel и PagingSource.

## Проверка

Основные сценарии проверялись вручную при запуске приложения:

- Загрузка объявлений.
- Прокрутка ленты и подгрузка следующих страниц.
- Поиск по объявлениям.
- Фильтрация по категориям.
- Отображение состояний загрузки и ошибок.

Автоматические тесты производительности и модульные тесты пока не добавлены.
